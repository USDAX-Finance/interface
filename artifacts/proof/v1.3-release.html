VaultEngine v1.3 — ABI Changes
New functions added to VaultEngine interface
🔒
pause() / unpause()
Owner-only. Halts depositCollateral, mintUsdax, liquidate. Repay & withdraw always remain open — users can always exit. Emits standard OZ Paused / Unpaused events.
📊
setDebtCeiling(uint256) / debtCeiling()
Owner-only setter. 0 = uncapped (default). Checked in mintUsdax against usdax.totalSupply(). Emits DebtCeilingUpdated(uint256 oldCap, uint256 newCap).

Keeper Bot — Hardening
artifacts/keeper/src/executor.ts
✓ Improvement
Actual Collateral Seized (on-chain)
Previously logged estimated collateral using hardcoded 5% liquidation bonus. Now uses parseEventLogs() (viem) to read the actual collateralSeized field from the on-chain Liquidated event in the tx receipt. Falls back to estimate with explicit WARNING if parsing fails.
⚠ Operational Safety
USDAX Balance Warning
Keeper now checks its own USDAX balance before each liquidation cycle.
CRITICAL — balance = 0, all liquidations will be skipped
WARNING — balance < 50 USDAX, missed liquidations possible
Gives operator advance warning before the bot silently misses vaults.
